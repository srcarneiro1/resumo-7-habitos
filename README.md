# Os 7 Hábitos — Guia de Leitura

**PT-BR:** Página web de leitura guiada sobre *Os 7 Hábitos das Pessoas Altamente Eficazes*, de Stephen R. Covey, com explicações e exemplos práticos.

**EN:** A web-based reading guide to Stephen R. Covey's *The 7 Habits of Highly Effective People*, featuring accessible explanations and practical examples.

## Tecnologias / Technologies

- HTML5
- CSS3
- Responsive Web Design

## Funcionalidades / Features

- Conteúdo organizado por temas e hábitos / Content organized by themes and habits
- Explicações em linguagem acessível / Accessible explanations
- Exemplos de aplicação prática / Practical examples
- Layout responsivo / Responsive layout

## Executar localmente / Run locally

Clone this repository and open `index.html` in a modern web browser. No backend or build process is required.

Clone este repositório e abra `index.html` em um navegador moderno. Não é necessário instalar dependências ou executar um servidor.
